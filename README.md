# Cocoa-Price-forecast-and-estimation
## Overview
This project aims to forecast cocoa prices using historical price data and climate variables. Machine learning and time series models are applied to analyze price trends and evaluate forecasting performance.

## Dataset
The project uses:
- **Cocoa Price Data:** Historical daily cocoa prices from 1994 to 2025.
- **Climate Data:** Weather variables from Ghana, including precipitation and temperature.

## File Structure
- `Datasets/` — Raw and processed datasets
- `Machine_Learning forecast.ipynb` — Machine learning implementation
- `457.Rmd` — Time Series Analysis
- `457 graphs/` — Graphs from Time Series Analysis
- `visualization charts-ML/` — Machine learning visualizations
